GPS Speedometer

Политика конфиденциальности - обновлено 7 октября 2026 г. | English

В этой политике описано, как GPS Speedometer обращается с вашими данными. У приложения нет учётных записей и собственных серверов, и оно не продаёт персональные данные. Ваши данные остаются на устройстве, пока вы сами не экспортируете их. Несколько необязательных функций обращаются к общедоступным сторонним сервисам и передают им приблизительные координаты. Они перечислены в разделах ниже, и каждую из них можно отключить.

Местоположение

Местоположение используется для расчёта скорости, расстояния и маршрута, пока идёт поездка. Пока приложение открыто, оно также используется для показа вашей позиции на карте и, если эти функции включены, для получения погоды и ограничений скорости (см. ниже). Маршруты поездок сохраняются только на устройстве вместе с записью о поездке и никогда не отправляются на сервер. За пределы устройства уходят только приблизительные координаты, описанные в разделах «Погода», «Знак ограничения скорости» и «Сетевые запросы».

Погода

Если функция погоды включена, приложение отправляет ваши текущие координаты сервису погоды, чтобы получить местные условия. Запрос содержит только широту и долготу: без идентификаторов, без данных о поездках, без персональной информации. Основной источник - Open-Meteo, резервный - MET Norway. Оба сервиса бесплатны, открыты и не требуют ключа API или учётной записи. Функцию погоды можно отключить в любой момент в настройках.

Знак ограничения скорости

Если знак ограничения скорости включён, приложение запрашивает у общедоступного сервиса данных OpenStreetMap (Overpass API, резервные серверы - overpass.private.coffee и maps.mail.ru) установленное ограничение скорости на ближайших дорогах. Запрос содержит только приблизительные координаты, округлённые до сетки примерно в 100 метров. В нём нет идентификаторов и данных о поездках. Результаты кэшируются на устройстве, чтобы запросов было меньше. Эти сервисы принадлежат третьим лицам и, как любой веб-сервер, видят ваш IP-адрес. Знак можно отключить в любой момент в настройках.

Названия мест

Чтобы показать название места для поездки, приложение может использовать встроенный геокодер Android. На большинстве устройств это системная служба, которая может передавать координаты в службу определения местоположения производителя устройства или Google. Она не относится к этому приложению и используется только при просмотре поездки.

Пульс и калории

Если вы включите функцию пульса в настройках, приложение сможет читать данные о пульсе и калориях из Health Connect. Эти данные поступают с ваших часов или фитнес-браслета и хранятся только вместе с соответствующей поездкой на вашем устройстве. Функцию можно отключить, а разрешение отозвать в любой момент.

История поездок

Записанные поездки хранятся в локальной базе данных на вашем устройстве. Поездки не покидают устройство, пока вы сами не экспортируете их в виде файлов GPX.

Настройки

Ваши настройки хранятся локально в Android DataStore. Они могут попадать в автоматическую резервную копию Android, если она у вас включена. Приложение их не передаёт.

Чего приложение не делает

  • Не требует учётных записей, адресов электронной почты и номеров телефона
  • Не использует рекламные идентификаторы и рекламные SDK
  • Не ведёт аналитику и телеметрию, не использует сторонние сервисы отчётов о сбоях
  • Не использует сторонние SDK, передающие персональные данные

Сетевые запросы

Приложение выполняет только следующие сетевые запросы:

  • Тайлы карты - запрашиваются у общедоступного сервиса VersaTiles. Запросы содержат только видимую на карте область. В них нет идентификаторов пользователя или устройства.
  • Спутниковые снимки - если вы выбрали спутниковый стиль карты, тайлы запрашиваются у сервиса Esri ArcGIS World Imagery, также только для видимой области.
  • Погода - когда функция погоды включена, приложение запрашивает текущие условия у Open-Meteo или MET Norway по вашим координатам. См. раздел «Погода» выше.
  • Ограничения скорости - когда знак ограничения скорости включён, приложение обращается к серверам Overpass API с приблизительными координатами. См. раздел «Знак ограничения скорости» выше.

Хранение данных

  • Поездки, путевые точки и метки на карте: локальная база данных (закрытое хранилище приложения)
  • Настройки: локальный Android DataStore
  • Данные пульса: хранятся вместе с поездкой в локальной базе данных

Автоматическая резервная копия Android может включать эти данные, если она у вас включена. Резервные копии Google защищены сквозным шифрованием.

Удаление данных

  • Одна поездка: откройте её в истории и удалите
  • Все поездки: Настройки > Данные > Удалить все поездки
  • Все метки на карте: Настройки > Данные > Удалить все точки
  • Всё сразу: Настройки > Данные > «Удалить все поездки», «Удалить все точки» и при желании «Сбросить все настройки», либо просто удалите приложение
  • Данные пульса: отключите функцию в настройках; сохранённые измерения удаляются вместе с поездкой

Дети

Приложение предназначено для пользователей от 18 лет. Оно не собирает данные ни о ком, включая детей. В нём нет учётных записей, сообщений и контента, которым можно делиться с другими пользователями.

Изменения

Если способы обработки данных изменятся, эта политика будет обновлена, а дата вверху страницы изменится.
